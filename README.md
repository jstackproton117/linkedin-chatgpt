# LinkedIn ChatGPT

This repository contains a simple content-pipeline project for drafting and logging LinkedIn posts.

## Structure

- pipeline/: Python scripts for fetching, reviewing, drafting, and logging posts
- templates/: Flask templates used by the web app
- data/: JSON data and generated drafts

## Getting started

1. Install dependencies from pipeline/requirements.txt
2. Run the app from the pipeline directory
3. Use the provided scripts to generate and review content
